## 
 **言叶之栞** 是一款专为日音爱好者、日语学习者与歌词翻译者打造的前端单文件 Web 应用。
项目支持日文歌词自动在汉字上标注假名、可以使用URL网页歌词（网易云音乐）一键提取，以及一键导出原生带注音的 **Word (`.doc`)** 与独立网页文档。


## ✨ 核心特性

### 1. 明朝体与双语排版系统
### 2. 智能分词与交互式改音引
### 3. 🔗 URL 链接一键提取歌词
- **多源网页解析**：支持直接粘贴 **Uta-Net (歌ネット)**、**Utaten**、**J-Lyric**、**网易云音乐**及通用日文歌词网页 URL，一键抓取曲名、歌手与歌词正文。
- **标签还原与双语自动分流**：自动将网页内置的 `<ruby>` 标签转化为可编辑的 `漢字(かな)` 格式，智能剔除 `.lrc` 时间轴标签（如 `[00:12.34]`）与作词作曲元数据，并自动识别「一日一中」交替文本，拆分为日文原词与中文译文两栏。
### 4. 多格式导出与响应式交互体验
- **一键生成 Word 文档 (`.doc`)**
- **HTML 与纯文本导出**
- **移动端适配**

## 📖 使用指南

1. **导入或输入歌词**
   - **空白自定义（默认）**：在左侧输入框直接粘贴日文歌词与中文译文，按行号自动实现双语对齐；点击任意输入框右侧的 `✕` 按钮可快速清空单项内容。
   - **URL 链接提取**：在「🔗 URL 链接提取歌词」栏粘贴歌词网页地址（或点击栏位右上角的「花の塔」「夜に駆ける」示例链接），点击 **⚡ 提取歌词** 自动填入。
   - **预设曲目体验**：点击工作台顶部的 `🎵 夜に駆ける` 或 `🌺 花の塔` 胶囊，一键加载完整双语排版范例。

2. **自定义特殊注音（当て字）**
   - **行内语法标注**：在日文歌词框中输入 `未来(あした)` 或点击输入框底部的快捷标签，预览区即刻渲染为指定读音。
   - **舞台点击修正**：直接点击右侧预览舞台上的任意带注音汉字，在弹窗中输入新读音并选择「全文同名词汇」或「仅当前所在行」，点击 **应用注音** 即可实时生效。

3. **定制明朝体版式与色彩**
   - 在上方 2×4 排版工作台中调节**日文字体**、**译文字体**、**字体大小**、**字间距**、**行高与字重**及**注音比例**。
   - 点击「自由取色」中的圆形色点，为日文、注音、译文挑选任意 RGB/HEX 色彩，或使用右侧下拉菜单一键切换 5 套二次元主题色盘。

4. **导出作品**
   - 点击导航栏右上角 **一键生成 Word** 下载 `.doc` 文档，或使用预览卡顶栏的 **复制 HTML**、**复制文本**、**导出网页** 按钮分享排版成果。

## 📐 核心排版规范参数

| 排版属性 | CSS 变量名 | 默认值 | 可调范围 / 说明 |
| :--- | :--- | :--- | :--- |
| **日文主字体栈** | `--font-jp` | `Hiragino Mincho ProN, Yu Mincho...` | 内置 7 套明朝体 / 手写体 / 圆体栈切换 |
| **中文译文字体栈** | `--font-zh` | `Songti SC, Noto Serif SC...` | 支持思源宋体、与日文同步、手写楷体、黑体 |
| **正文基准字号** | `--lyric-font-size` | `26px` | 支持 `12px` ～ `72px` 手动输入与 5 档预设 |
| **防碰撞行高** | `--lyric-line-height` | `2.45` | 支持 `2.0` ～ `3.0`，预留充足 `<rt>` 纵向空间 |
| **振假名字号比例** | `--ruby-font-scale` | `0.55em` | 支持 `0.45em` / `0.50em` / `0.55em` / `0.62em` / `0.70em` |
| **字间距** | `--lyric-letter-spacing` | `0.05em` | 支持 `-0.05em` ～ `0.50em` 无级调节 |
| **双语字号级差** | `--zh-font-scale` | `0.76` | 译文字号约为日文原文的 `76%`，层次分明 |
